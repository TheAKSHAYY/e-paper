# @epaper-studio/typography

Multilingual font cascades, optical weight adjustments, and e-ink readability definitions.

## Scope & Capabilities

- Font registry optimized for 200–300 DPI e-paper displays (preventing hairline strokes from disappearing under e-ink electrophoresis).
- Fallback cascades covering Latin, Cyrillic, Arabic (RTL), CJK, and Devanagari.
- Metrics normalization to preserve column heights across languages.
