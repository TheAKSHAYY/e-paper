E-Paper Maker Research Pack

Files:
- research-guide.md       Research synthesis, font/licensing notes, Hindi text rules, grids, UX, export checks and sources.
- font-catalog.json       Role-based font catalog and suggested Hindi font combinations.
- layout-presets.json     Five starter layout recipes with grids, margins, colours, type scale and story modules.
- paper-sizes.json        Paper formats and export profiles; newspaper-size caveats included.
- qa-checklist.json       Hindi proof strings, viewport tests and PDF release gates.

Important:
- Grid counts, margins and type sizes are suggested baseline values, not universal newspaper standards.
- Verify the actual font files, included weights and license files in the source repository before shipping.
- Newspaper trim sizes vary by printer. Always support custom dimensions and printer-specific print settings.
- Before production release, render exported PDFs to images and inspect Hindi shaping at actual size.
