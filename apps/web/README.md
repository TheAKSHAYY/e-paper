# @epaper-studio/web

Interactive browser-based studio application for authoring, styling, and previewing e-paper layouts.

## Technology Stack

- React 19 + TypeScript
- Vite build tooling
- Shared design tokens from `@epaper-studio/ui`
- Document schema from `@epaper-studio/document-schema`

## Available Scripts

- `pnpm dev`: Start local development server on port 5173
- `pnpm build`: Typecheck and produce static production bundle in `dist/`
- `pnpm preview`: Locally preview production build
